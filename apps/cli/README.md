# @taskforge/cli

The `tf` command for [TaskForge](https://github.com/eder/taskforge): an open-source control plane that coordinates Claude Code, Codex CLI and Google Antigravity through planning, isolated Git worktrees, verification, recovery and explicit delivery.

```bash
tf doctor   # check your environment
tf          # interactive control plane
```

Requires Node.js 22+, Git, and at least one supported coding-agent CLI. See the [project README](https://github.com/eder/taskforge#readme) and [usage guide](https://github.com/eder/taskforge/blob/main/docs/usage.md).
